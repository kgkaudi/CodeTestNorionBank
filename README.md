# Gothenburg Toll Fee

ASP.NET Core 10 Web API for calculating congestion tax for vehicles passing toll stations in Gothenburg.

## Technologies

- C#
- ASP.NET Core 10
- xUnit
- Swagger / OpenAPI

## Projects

- `GothenburgTollFee.Api` - HTTP API
- `GothenburgTollFee.Core` - Business/domain logic
- `GothenburgTollFee.Tests` - Automated tests
